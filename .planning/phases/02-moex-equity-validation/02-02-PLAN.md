  <action>
    **Step 1: Run cointegration tests on all pairs**

    Run the fixed cointegration script (from Plan 01) to test all 8 candidate pairs:
    ```bash
    uv run python scripts/test_pairs_cointegration.py
    ```

    From results, apply decision criteria:
    - KEEP pair if: p-value < 0.05 AND half-life < 30 days AND Hurst < 0.5
    - DISABLE pair if any criterion fails
    - Update pairs lists in all 3 ru_* YAML presets: only include passing pairs
    - If ALL pairs fail cointegration, disable pairs strategy entirely on affected segments and redistribute weight
    - For borderline cases (p-value 0.05-0.10): use Claude's discretion per CONTEXT.md, but lean toward dropping

    **Step 2: Optuna tuning per segment**

    Run Optuna tuning for each MOEX segment. Maximum 5 tuning iterations total (per user decision). Use existing guardrails (DSR haircut, holdout validation, perturbation check).

    ```bash
    uv run python scripts/tune_strategy_params.py --segment ru_blue_chips --n-trials 50
    uv run python scripts/tune_strategy_params.py --segment ru_energy --n-trials 50
    uv run python scripts/tune_strategy_params.py --segment ru_finance --n-trials 50
    ```

    After each Optuna run:
    1. Review best trial params -- check they pass perturbation test and holdout validation
    2. Apply best params to the YAML preset ONLY IF they improve OOS metrics
    3. Record metrics for comparison

    Key parameters to include in Optuna search space (discretion areas from CONTEXT.md):
    - ADX regime routing thresholds (trend_threshold, mr_threshold)
    - Bollinger Band std_dev (no floor constraint)
    - max_hold_bars
    - min_combined_confidence, min_exit_confidence
    - Strategy-specific min_confidence values
    - OU window size
    - Dual momentum lookback periods

    **Anti-overfitting discipline:**
    - Walk-forward OOS metrics are the gate, NOT in-sample
    - Reject any parameter set with max drawdown > 20%
    - If holdout degradation ratio < 0.50, reject that trial
    - Track trade count: PF with < 30 trades is noise
