    **ERR-01 -- GARCH NaN fallback (per ERR-01):**

    1. Add `import structlog` and `_log = structlog.get_logger()` to garch.py.

    2. Create a helper `_rolling_vol_fallback(returns: list[float]) -> float` that computes
       `std(returns) * sqrt(252)`. If len(returns) < _MIN_RETURNS_REALIZED (2), return NaN.

    3. Modify `fit_forecast()`:
       - When `len(returns) < _MIN_RETURNS`: instead of `return float("nan")`, call `_rolling_vol_fallback(returns)`. Log `_log.warning("garch_insufficient_data", n_returns=len(returns), fallback="rolling_vol")`.
       - In the `except Exception` block: call `_rolling_vol_fallback(returns)` instead of `return float("nan")`. Log `_log.warning("garch_fit_failed", fallback="rolling_vol", exc_info=True)`.
       - When variance is non-finite or <= 0: call `_rolling_vol_fallback(returns)`. Log `_log.warning("garch_invalid_variance", fallback="rolling_vol")`.
       - When annualized_vol is non-finite or <= 0: same pattern.

    4. Modify `forecast_garch_vol()` to call `fit_forecast_safe()` instead of `fit_forecast()` so it inherits the fallback behavior.

    **ERR-02 -- EventBus exception narrowing (per ERR-02):**

    1. Add `import structlog` and `_log = structlog.get_logger()` to events.py (if not present).

    2. In `create_group()`, replace:
       ```python
       with contextlib.suppress(Exception):
       ```
       with:
       ```python
       try:
           await self._redis.xgroup_create(stream, group, id=start_id, mkstream=True)
       except redis.ResponseError:
           pass  # Group already exists -- expected
       except Exception:
           _log.error("eventbus_create_group_failed", stream=stream, group=group, exc_info=True)
           raise
       ```

    3. Remove the `import contextlib` if no longer used elsewhere in the file.

    **Tests:**

    - In test_events.py: add test that create_group suppresses redis.ResponseError but re-raises other exceptions (e.g., ConnectionError).
