    1. Create `src/finalayze/data/fetchers/telegram_reader.py` (Layer 2):
       - `from __future__ import annotations`
       - Import `structlog`, `UUID`, `datetime`, `timedelta`, `UTC` from stdlib
       - TYPE_CHECKING import for `TelegramClient` from telethon

       Class `TelegramChannelReader`:
       ```python
       _MAX_MESSAGES_PER_CHANNEL = 50  # Cap per poll cycle

       def __init__(
           self,
           api_id: int,
           api_hash: str,
           session_name: str = "finalayze_reader",
       ) -> None:
           self._api_id = api_id
           self._api_hash = api_hash
           self._session_name = session_name
           self._configured = api_id != 0 and api_hash != ""
       ```

       Method `async def fetch_recent_messages(self, channels: list[str], since_minutes: int = 5) -> list[NewsArticle]`:
       - If not self._configured: log debug "telegram_reader_not_configured", return []
       - Import TelegramClient inside method (lazy import to avoid import error when telethon not configured)
       - `cutoff = datetime.now(UTC) - timedelta(minutes=since_minutes)`
       - Create TelegramClient(self._session_name, self._api_id, self._api_hash)
       - `async with client:` iterate channels
       - For each channel: `async for msg in client.iter_messages(channel, offset_date=cutoff, reverse=True, limit=_MAX_MESSAGES_PER_CHANNEL)`
       - Skip if not msg.text or len(msg.text.strip()) < 10 (filter noise)
       - Convert to NewsArticle:
         - id=uuid4()
         - source=f"telegram:{channel}"
         - title=msg.text[:100] (first 100 chars as title)
         - content=msg.text
         - url=f"https://t.me/{channel.lstrip('@')}/{msg.id}"
         - language="ru"
         - published_at=msg.date (already UTC-aware from Telethon)
         - scope="russia"
       - Wrap each channel iteration in try/except, log warning on failure, continue
       - Return combined articles list

       - Mock `client.iter_messages` as an async generator
       - Test all behaviors listed above
