<objective>
Build the Docker Compose sandbox stack with Grafana observability, implement APScheduler SQLAlchemy job store for job persistence across restarts, add structured JSON cycle logging for post-mortem analysis, and wire TradingLoop startup into the FastAPI lifespan so the container runs both API and trading.
