_WINDOW_INTERVALS: dict[str, str] = {

}

`SentimentRow` NamedTuple:
```python
class SentimentRow(NamedTuple):
    bucket: datetime
    avg_score: float | None
    article_count: int
```

`SentimentStore` class:
- `__init__(self, session_factory: async_sessionmaker[AsyncSession]) -> None` — stores `self._factory = session_factory`
- `async def get_rolling(self, ticker: str, *, window: str = "7d", market_id: str = "moex") -> list[SentimentRow]`

Implementation of `get_rolling`:
1. Look up `interval = _WINDOW_INTERVALS.get(window, "7 days")` — invalid windows fall back to 7d.
2. Build SQL with `text()`:
   ```sql
   SELECT bucket, avg_score, article_count
   FROM sentiment_7d_avg
   WHERE symbol    = :symbol
     AND market_id = :market_id
     AND bucket   >= NOW() - INTERVAL :interval
   ORDER BY bucket ASC
   ```
   CRITICAL: Use SQLAlchemy `text()` with named `:param` bindings — never f-strings or `.format()`.
3. Execute query within `async with self._factory() as session:` context.
4. `rows = result.fetchall()` — no `await` on fetchall (SQLAlchemy 2.0 sync method on CursorResult).
5. Convert each row to `SentimentRow`:
   - `bucket=row.bucket`
   - `avg_score=float(row.avg_score) if row.avg_score is not None else None`
   - `article_count=int(row.article_count)`
6. Return the list. If `rows` is empty, returns `[]` naturally — no special handling needed.

Add a module docstring: "Layer 2 read-only accessor for rolling sentiment aggregates from the sentiment_7d_avg continuous aggregate view."

Run the tests from Task 1 — all 6 must pass (GREEN phase).
