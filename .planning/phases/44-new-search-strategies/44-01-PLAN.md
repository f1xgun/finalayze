**`_generate_feature_candidates(base_features: list[str], all_features: list[dict[str, float]], labels: list[int], cap: int) -> tuple[list[str], list[dict[str, float]]]`:**
  - Generate three types of engineered features from base_features:
    a. **Lag ratios**: for features containing "close" or "volume": `feat_lag5_ratio = feat[t] / feat[t-5]` (use shift=5 on pandas Series). Use lags [5, 10, 20].
    b. **Rolling z-scores**: for numeric features: `feat_zscore_20 = (feat - rolling_mean_20) / rolling_std_20`. Windows [20, 60].
    c. **Cross-feature interactions**: for pairs (RSI-like x volume-like): `rsi_x_volume_ratio = rsi * volume_ratio`. Only generate for features matching known pairs: any feature containing "rsi" paired with any containing "volume".
  - Truncate generated feature list to `cap` (take first `cap` candidates by generation order).
  - Return (new_feature_names, augmented_features_dicts) where augmented_features_dicts is original features dicts with new columns appended.

**`_filter_by_permutation_importance(features: list[dict[str, float]], labels: list[int], candidate_names: list[str], baseline_features: list[str]) -> list[str]`:**
  - Build DataFrame from features using only candidate_names columns.
  - Train a single XGBoostModel on the full feature set (baseline + candidates).
  - Use `sklearn.inspection.permutation_importance` with n_repeats=5, random_state=42.
  - Keep only candidates whose mean importance > 0.
  - Return surviving candidate names.

**`generate_feature_engineering_experiments(baseline_features: list[str], all_features: list[dict[str, float]], labels: list[int], n_samples: int) -> list[ExperimentConfig]`:**

  - If no candidates survive, return [].
