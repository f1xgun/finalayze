## File 1: `src/finalayze/dashboard/pages/experiment_detail.py`

**Module structure:** `from __future__ import annotations`, imports at top, `render(api: ApiClient) -> None` as sole public function, NO `st.*` calls at module level.

**Implementation:**

1. **Imports:** `streamlit as st`, `pandas as pd`, `plotly.graph_objects as go`, `ApiClient`, `ExperimentManager`, `DebateManager`, `ExperimentStatus`.

2. **Title:** `st.title("Experiment Detail")`

3. **Experiment ID from URL:** Read `experiment_id = st.query_params.get("experiment_id", "")`. If empty, show `st.warning("No experiment selected. Go to the Experiment List to pick one.")` and return.

4. **Load experiment:** `mgr = ExperimentManager()`, `exp = mgr.read_experiment(experiment_id)` wrapped in try/except `FileNotFoundError` -> show `st.error(f"Experiment '{experiment_id}' not found.")` and return.

5. **Status header:** Show experiment_id and status using the status badge pattern:
   ```python
   _STATUS_DISPLAY = {
       "accepted": ("success", "ACCEPTED"),
       "rejected": ("error", "REJECTED"),
       "inconclusive": ("warning", "INCONCLUSIVE"),
       "running": ("info", "RUNNING"),
       "pending": ("info", "PENDING"),
       "completed": ("info", "COMPLETED"),
   }
   ```
   Call `getattr(st, fn_name)(label)` for the appropriate status.

6. **Hypothesis section:** `st.subheader("Hypothesis")` then `st.write(exp.hypothesis)`.

7. **Success criteria section:** `st.subheader("Success Criteria")` then `st.write(f"**Metric:** {exp.success_criteria.metric}")`, `st.write(f"**Threshold:** {exp.success_criteria.operator} {exp.success_criteria.threshold}")`.

8. **Debate context section (per UI-EXP-02 "why"):**
   ```python
   st.subheader("Debate Context")
   if exp.debate_id:
       try:
           dm = DebateManager()
           debate = dm.read_debate(exp.debate_id)
           st.write(f"**Topic:** {debate.topic}")
           st.write(f"**Agents:** {', '.join(debate.agents)}")
           if debate.resolution:
               st.write(f"**Resolution:** {debate.resolution}")
           if debate.arbiter_report:
               st.write("**Arbiter Report:**")
               st.json(debate.arbiter_report.model_dump())
       except FileNotFoundError:
           st.warning(f"Linked debate '{exp.debate_id}' not found.")
   else:
       st.info("No debate linked to this experiment.")
   ```

9. **Backtest results section with A/B/AB comparison chart (per UI-EXP-02 "what happened"):**
   ```python
   st.subheader("Backtest Results")
   if not exp.results:
       st.info("No backtest results yet.")
   else:
       # A vs B vs A+B grouped bar chart
       metrics_of_interest = ["sharpe", "profit_factor", "max_drawdown", "win_rate", "total_trades"]
       fig = go.Figure()
       for result in exp.results:
           vals = [float(result.metrics.get(m, 0)) for m in metrics_of_interest]
           fig.add_trace(go.Bar(name=result.run_name, x=metrics_of_interest, y=vals))
       fig.update_layout(
           barmode="group",
           height=400,
           title="Metric Comparison",
           xaxis_title="Metric",
           yaxis_title="Value",
       )
       st.plotly_chart(fig, use_container_width=True)

       # Delta comparison table
       st.subheader("Comparison Table")
       rows = []
       for result in exp.results:
           row = {"Run": result.run_name, "Iteration": result.iteration_name}
           for m in metrics_of_interest:
               row[m] = float(result.metrics.get(m, 0))
           rows.append(row)
       df = pd.DataFrame(rows)
       st.dataframe(df, use_container_width=True)
   ```

10. **Verdict section (if terminal status):**
    If `exp.verdict`: `st.subheader("Verdict")`, `st.write(f"**Decision:** {exp.verdict}")`, `st.write(f"**Reasoning:** {exp.reasoning}")`.

11. **Preset overrides section (if present):**
    If `exp.preset_overrides`: `st.subheader("Preset Overrides")`, `st.json(exp.preset_overrides)`.

## File 2: `src/finalayze/dashboard/pages/decision_history.py`

**Module structure:** Same pattern — `from __future__ import annotations`, `render(api: ApiClient) -> None`, NO module-level `st.*` calls.

**Implementation:**

   - `st.write(f"**Reasoning:** {exp.reasoning}")`
