2. **Add `_portfolio_review_cycle()` method** (sync, called by APScheduler):
   ```python
   def _portfolio_review_cycle(self) -> None:
       """APScheduler callback -- dispatches async review without blocking.

       Fires at 16:00 UTC = 19:00 MSK daily (after MOEX close at 18:40 MSK).
       """
       if self._llm_client is None:
           _log.info("portfolio_review_skipped", reason="no LLM client configured")
           return
       if self._async_loop is None or self._async_loop.is_closed():
           return
       asyncio.run_coroutine_threadsafe(
           self._run_portfolio_review_async(),
           self._async_loop,
       )
       # No .result() -- fire-and-forget (same pattern as anomaly enrichment)
   ```

3. **Add `_run_portfolio_review_async()` method** (async, fire-and-forget):
   - Calls `self._gather_portfolio_data()` to get portfolio state
   - Calls `await asyncio.wait_for(self._llm_client.parse_structured(prompt=build_review_prompt(portfolio_data), system=PORTFOLIO_REVIEW_SYSTEM_PROMPT, response_model=PortfolioReviewResult), timeout=REVIEW_LLM_TIMEOUT)`
   - Formats result: `message = format_review_telegram(result)`
   - Sends via `await self._alerter._send(message)`
   - Wraps entire body in try/except Exception, logs `portfolio_review_llm_failure` on any error (graceful degradation per PFRA-01)
   - MUST NOT reference BrokerRouter, place_order, or generate_signal (PFRA-03)

4. **Add `_gather_portfolio_data()` method** (sync):
   - Iterates `self._circuit_breakers` keys (market_ids)
   - For each: `broker = self._broker_router.route(market_id)`, then `broker.get_portfolio()` and `broker.get_positions()`
   - Wraps each broker call in try/except Exception, logs warning on failure (same pattern as _daily_reset)
   - Returns `dict[str, object]` with market_id keys and position/equity/cash data
