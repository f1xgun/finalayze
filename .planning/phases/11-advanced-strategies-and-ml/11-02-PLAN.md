   - `usdrub_vol`: 20-day rolling std of log returns on lagged fx_rates series. Clip to [0, 0.10].
   - Default 0.0 when moex_data is None or insufficient data.

   - `brent_return`: `np.log(candles[-lag-1].close / candles[-lag-2].close)` where lag=_EXTERNAL_DATA_LAG_BARS. Clip to [-0.15, 0.15].
   - Default 0.0 when moex_data is None or insufficient Brent data.
