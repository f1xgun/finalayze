    Constructor accepts optional `debate_manager: DebateManager | None = None` and `experiment_manager: ExperimentManager | None = None` for dependency injection (default to new instances).

    Method `run(self, outputs: list[AgentOutput]) -> list[str]`:
    1. Create a FRESH `ConflictDetector()` (avoids pitfall 4 from research — no stale dedup)
    2. Call `detector.detect(outputs)` to get `list[ConflictReport]`
    3. If empty, return `[]` (short-circuit per Claude's discretion)
    4. Group conflicts by unique sets of agent_names (so unrelated conflicts between different agent pairs produce separate debates)
    5. For each conflict group:
       a. Generate debate_id using `hashlib.sha256` of sorted agent names + ISO-minute timestamp
       b. Derive topic from first conflict's involved_claims statements (truncate to 100 chars)
       c. Call `self._dm.create_debate(debate_id, topic, agent_names)`
       d. For each output whose agent_name is in the conflict group: call `self._dm.add_agent_position(debate_id, output.agent_name, output)`
    6. Return list of debate_ids

    Method `finalize_debate(self, debate_id: str, report: FactCheckReport) -> str | None`:
    1. Call `self._dm.add_arbiter_report(debate_id, report)`
    2. If `report.has_contradictions`:
       a. Generate experiment_id: `f"exp-{debate_id[:12]}"`
       b. Build hypothesis from contradicted claims
       c. Use default SuccessCriteria(metric="profit_factor", threshold=1.1, operator=">=")
       d. Call `self._em.create_experiment(experiment_id, hypothesis, success_criteria, debate_id=debate_id)`
       e. Return experiment_id
    3. Else: call `self._dm.resolve_debate(debate_id, "No contradictions — claims verified by arbiter")` and return None
