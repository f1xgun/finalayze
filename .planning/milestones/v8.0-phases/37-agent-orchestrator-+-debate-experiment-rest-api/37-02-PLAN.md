## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-04 | Spoofing | REST endpoints | mitigate | X-API-Key auth via `api_key_auth` dependency with hmac.compare_digest — same as all existing endpoints |
| T-37-05 | Tampering | POST /debates request body | mitigate | Pydantic v2 validates AgentOutput structure (frozen model, field validators on confidence). Invalid JSON rejected with 422. |
| T-37-06 | Information Disclosure | GET /debates/{id} | accept | Debate files contain agent recommendations (not PII or secrets). API key required for access. Acceptable for single-developer system. |
| T-37-07 | Denial of Service | POST /debates with huge outputs list | mitigate | FastAPI default body size limit (1MB). ConflictDetector O(n^2) bounded by practical agent count (3-6). |
</threat_model>
