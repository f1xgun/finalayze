```python
class ConflictType(StrEnum):
    DIRECTION = "direction"
    METRIC = "metric"
    STATEMENT = "statement"

class ConflictSeverity(StrEnum):
    CRITICAL = "critical"
    HIGH = "high"
    LOW = "low"

class ConflictReport(BaseModel):
    model_config = ConfigDict(frozen=True)
    conflict_id: str
    conflict_type: ConflictType
    severity: ConflictSeverity
    involved_claims: list[Claim] = Field(min_length=2)
    agent_names: list[str] = Field(min_length=2)
    detected_at: datetime
    confidence_delta: float | None = None

class Claim(BaseModel):
    model_config = ConfigDict(frozen=True)
    statement: str
    source: ClaimSource  # FileLineSource | MetricSource discriminated union
    confidence: float  # [0.0, 1.0]

class AgentOutput(BaseModel):
    model_config = ConfigDict(frozen=True)
    agent_name: str
    recommendation: str
    claims: list[Claim] = Field(min_length=1)
    timestamp: datetime

class MetricSource(BaseModel):
    model_config = ConfigDict(frozen=True)
    kind: Literal["metric"] = "metric"
    metric_name: str
    value: float
    iteration: str
```

Class `ConflictDetector`:
- `__init__(self) -> None`: Initialize `self._seen_conflicts: set[str] = set()`
- `detect(self, outputs: list[AgentOutput]) -> list[ConflictReport]`: Iterate `combinations(outputs, 2)`, call `_compare_pair()` for each, return deduplicated list
- `reset(self) -> None`: Clear `_seen_conflicts` set
- `_compare_pair(self, a: AgentOutput, b: AgentOutput) -> list[ConflictReport]`: Check direction, metric, statement conflicts in order
- `_check_direction(self, a: AgentOutput, b: AgentOutput) -> ConflictReport | None`:
  - Extract uppercase words from `a.recommendation` and `b.recommendation`
  - If one intersects `_DIRECTION_BUY` and other intersects `_DIRECTION_SELL`, return DIRECTION/CRITICAL
  - Check confidence delta: compute max confidence across all claims from each agent. If delta <= 0.15, skip (return None)
  - Build dedup key: `sha256(sorted([a.agent_name, b.agent_name]) + sorted(topics) + "direction")`
  - If key in `_seen_conflicts`, return None
  - Add key to `_seen_conflicts`, return ConflictReport
- `_check_metrics(self, a: AgentOutput, b: AgentOutput) -> list[ConflictReport]`:
  - Match claim pairs where both have MetricSource with same `metric_name` AND same `iteration`
  - Relative divergence = `abs(va - vb) / max(abs(va), abs(vb))` (symmetric, using max as denominator)
  - If divergence > `_METRIC_CONTRADICTION_THRESHOLD` (0.15): conflict detected
  - Severity: HIGH if divergence > 0.30, else LOW
  - Apply confidence delta filter and dedup
- `_check_statements(self, a: AgentOutput, b: AgentOutput) -> list[ConflictReport]`:
  - For each claim pair across the two outputs, compute `difflib.SequenceMatcher(None, s1, s2).ratio()`
  - If ratio > 0.85 AND recommendations are divergent (one has BUY-keyword, other has SELL-keyword): STATEMENT/LOW
  - Apply confidence delta filter and dedup
- `_extract_topic(self, statement: str) -> str`: Extract primary topic via regex `r'\b([A-Z]{2,}|[a-z_]+_[a-z_]+)\b'`, return first match lowered or first 20 chars
- `_dedup_key(self, agents: list[str], topics: list[str], conflict_type: ConflictType) -> str`: SHA-256 of `str(sorted(agents)) + str(sorted(topics)) + str(conflict_type)`

Confidence delta calculation: For a pair of outputs (a, b), take `max(c.confidence for c in a.claims)` and `max(c.confidence for c in b.claims)`. Delta = `abs(max_a - max_b)`. If delta <= 0.15, do not produce a conflict for that pair.
