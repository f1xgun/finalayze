```python
class DebateStatus(StrEnum):
    OPEN = "open"
    RESOLVED = "resolved"
    ESCALATED = "escalated"

class FileLineSource(BaseModel):
    kind: Literal["file"] = "file"
    path: str; line: int; excerpt: str

class MetricSource(BaseModel):
    kind: Literal["metric"] = "metric"
    metric_name: str; value: float; iteration: str

ClaimSource = Annotated[FileLineSource | MetricSource, Field(discriminator="kind")]

class Claim(BaseModel):
    statement: str; source: ClaimSource; confidence: float

class AgentOutput(BaseModel):
    agent_name: str; recommendation: str; claims: list[Claim]; timestamp: datetime

class ClaimVerdict(StrEnum):
    VERIFIED = "verified"; CONTRADICTED = "contradicted"; UNTESTABLE = "untestable"

class ClaimCheckResult(BaseModel):
    claim: Claim; verdict: ClaimVerdict; evidence: str

class FactCheckReport(BaseModel):
    debate_id: str; arbiter_timestamp: datetime; results: list[ClaimCheckResult]
    has_contradictions: bool (property)
    to_markdown() -> str

class DebateState(BaseModel):
    debate_id: str; topic: str; status: DebateStatus; created: str
    agents: list[str]; arbiter_report: FactCheckReport | None
    resolution: str | None; experiment_id: str | None
```

```python
from __future__ import annotations

import json
from datetime import datetime
from pathlib import Path
from typing import TYPE_CHECKING

import yaml

if TYPE_CHECKING:
    from finalayze.core.schemas import AgentOutput, DebateState, FactCheckReport

class DebateManager:
    """Manages structured debate files in a directory.

    Each debate is a markdown file with YAML frontmatter matching the
    DebateState schema. The manager provides CRUD operations for
    creating, reading, updating, and listing debates.
    """

    def __init__(self, debates_dir: Path | None = None) -> None:
        self._dir = debates_dir or Path(".planning/debates")
        self._dir.mkdir(parents=True, exist_ok=True)
```

Methods to implement:
- `create_debate(debate_id: str, topic: str, agents: list[str]) -> Path` — writes `{debate_id}.md` with YAML frontmatter (status=open, created=today's date, arbiter_report=null, resolution=null, experiment_id=null) and a markdown heading `# Debate: {topic}`.
- `read_debate(debate_id: str) -> DebateState` — reads `{debate_id}.md`, splits on `---` delimiters, parses YAML frontmatter with `yaml.safe_load()`, returns `DebateState(**frontmatter)`. Raises `FileNotFoundError` if file missing.
- `resolve_debate(debate_id: str, resolution: str) -> None` — reads file, updates `status: resolved` and `resolution:` in frontmatter, rewrites file.
- `escalate_debate(debate_id: str, experiment_id: str) -> None` — reads file, updates `status: escalated` and `experiment_id:` in frontmatter, rewrites file.
- `list_debates() -> list[str]` — returns sorted list of debate_ids (filename stems) from directory.
- `add_agent_position(debate_id: str, agent_name: str, agent_output: AgentOutput) -> None` — appends `## {agent_name} Position\n\n{recommendation}\n\n### Claims\n\n{formatted claims}` to the markdown body.
- `add_arbiter_report(debate_id: str, report: FactCheckReport) -> None` — updates frontmatter `arbiter_report` field (serialize report to dict via `report.model_dump(mode="json")`) and appends `## Arbiter Fact-Check\n\n{report.to_markdown()}` to body.

Internal helper `_read_file(debate_id) -> tuple[dict, str]` returns (frontmatter_dict, body_text). Internal helper `_write_file(debate_id, frontmatter_dict, body_text) -> None` writes YAML frontmatter + body.

Use `yaml.safe_load()` for parsing and `yaml.dump(default_flow_style=False, allow_unicode=True, sort_keys=False)` for writing.

For serializing `FactCheckReport` into YAML frontmatter, use `report.model_dump(mode="json")` which handles datetime serialization. When reading back, the `arbiter_report` field in frontmatter will be a dict — pass it through `FactCheckReport(**dict_value)` only in `read_debate()`.

**Body structure (implement all sections):**

**Section 1: Role** — "You are the Arbiter Agent for the Finalayze trading system. Your role is to independently verify claims made by other agents in structured debates. You do NOT make trading recommendations — you only verify facts."

**Section 2: Input Format** — Document that the arbiter receives:
- `debate_id`: string identifier for the debate
- Two or more `AgentOutput` objects (JSON), each containing `agent_name`, `recommendation`, and `claims` list
- Each claim has `statement`, `source` (either `FileLineSource` or `MetricSource`), and `confidence`

**Section 3: Verification Protocol** — Two paths:

Path A — Code Claims (`source.kind == "file"`):
1. Run `ast-index outline {source.path}` to confirm file exists and is indexed
2. Read the file at `source.line` and compare against `source.excerpt`
3. If line+excerpt match exactly -> VERIFIED
4. If excerpt found at a different line -> VERIFIED (note: "line shifted to {actual_line}")
5. If excerpt not found anywhere in the file -> CONTRADICTED
6. If file does not exist -> UNTESTABLE

Path B — Metric Claims (`source.kind == "metric"`):
1. Read `results/iterations/history.jsonl` line by line
2. Find the record where `name` matches `source.iteration`
3. Extract `metrics.{source.metric_name}` from the record
4. If `abs(actual - source.value) <= 0.01` -> VERIFIED
5. If value differs by more than 0.01 -> CONTRADICTED (include actual value in evidence)
6. If iteration or metric not found -> UNTESTABLE

**Section 4: Output Format** — Produce a structured markdown report with these exact section headers: `## Verified`, `## Contradicted`, `## Untestable`, `## Summary`. Each claim entry formatted as `- **{claim.statement}** — Evidence: {what was found}`. Summary includes total counts and recommendation (RESOLVE if no contradictions, ESCALATE if any contradictions).

**Section 5: Important Rules:**
- NEVER make judgments about trading strategy merit — only verify factual claims
- Always validate `FileLineSource.path` starts with `src/` or `tests/` or `config/` or `docs/` — reject paths outside project root
- Use tolerance of 0.01 for float metric comparisons
- If `history.jsonl` does not exist or is empty, all metric claims are UNTESTABLE
- Run `ast-index rebuild` before verification if the last rebuild was more than 1 hour ago
