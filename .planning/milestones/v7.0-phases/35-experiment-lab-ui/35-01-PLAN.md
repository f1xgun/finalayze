Create `src/finalayze/dashboard/pages/experiments_list.py` implementing the full Experiments List page per UI-EXP-01.

**Module structure:** Follow signals.py pattern — `from __future__ import annotations`, imports at top, `render(api: ApiClient) -> None` as the sole public function, all `st.*` calls inside `render()` or private helpers.

**Implementation details:**

1. **Imports:** `streamlit as st`, `pandas as pd`, `ApiClient` from dashboard, `ExperimentManager` from core, `ExperimentStatus` from schemas.

2. **Title:** `st.title("Experiment Lab")`

3. **Refresh button:** `st.button("Refresh")` that calls `st.rerun()` when clicked (matches existing sandbox.py pattern — no cache_data needed since ExperimentManager reads files directly).

4. **Data loading:** Instantiate `ExperimentManager()` (default path `.planning/experiments/`). Call `mgr.list_experiments()`. For each ID, `mgr.read_experiment(eid)` wrapped in try/except `FileNotFoundError` (skip broken files silently).

5. **Empty state:** If no experiments loaded, display `st.info("No experiments found. Create experiments via ExperimentManager.")` and return.

6. **Filters (per CONTEXT.md locked decisions):**
   - Status dropdown: `st.selectbox("Filter by status", ["All"] + sorted_unique_statuses)` where statuses come from loaded experiments.
   - Text search: `st.text_input("Search hypothesis", "")` — case-insensitive substring match on `exp.hypothesis`.
   - Apply both filters before display.

7. **DataFrame display:**
   Build a list of dicts with columns: `ID`, `Status`, `Hypothesis` (truncated to 80 chars), `Created`, `Criteria` (e.g. "sharpe >= 0.15"), `Runs` (len of results), `Sharpe`, `PF`.
   - For Sharpe and PF: extract from the LAST result's metrics dict if results exist, else None. Always cast with `float()` and default to `None` if missing.
   - Display with `st.dataframe(df, use_container_width=True)`.
   - Apply gradient coloring on Sharpe and PF columns using `.style.background_gradient(subset=gradient_cols, cmap="RdYlGn")` — same pattern as signals.py.

8. **Navigation buttons:** Below the dataframe, for each filtered experiment, show a `st.button(f"View {exp.experiment_id}")` that sets `st.query_params["experiment_id"] = exp.experiment_id` and calls `st.switch_page("pages/experiment_detail.py")`.

**CRITICAL constraints:**
- NO `st.*` calls at module level (breaks smoke tests).
- All metric values from `ExperimentResult.metrics` dict MUST be cast with `float()` — values may be strings from YAML deserialization.
- Handle `FileNotFoundError` on individual experiment reads gracefully (skip, don't crash).
- Status values come from `ExperimentStatus` enum — compare with `.value` or use string representation.
