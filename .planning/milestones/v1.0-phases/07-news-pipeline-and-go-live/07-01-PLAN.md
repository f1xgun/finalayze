       - Class `RssNewsFetcher` with `__init__(self, feed_urls: list[str], rate_limiter: RateLimiter | None = None)`
       - `_seen_urls: OrderedDict[str, None]` for bounded LRU dedup (max 5000 entries)

       - `fetch_news(self) -> list[NewsArticle]` method:
         - Iterates feed_urls, calls `feedparser.parse(url)` for each

         - Skip entries with empty url or url already in _seen_urls
         - Add url to _seen_urls; if len > MAX_SEEN_SIZE, pop oldest (FIFO via popitem(last=False))
         - Wrap each entry parse in try/except, log warning on failure, continue
         - If rate_limiter provided, call `rate_limiter.acquire()` before each feed URL
         - Return list of NewsArticle with language="ru", scope="russia"
       - `_parse_published(self, entry: Any) -> datetime` helper:
         - Use `entry.get("published_parsed")` -> `datetime(*tp[:6], tzinfo=UTC)` if available
         - Fallback: try `dateutil.parser.parse(entry.get("published", ""))` with UTC
         - Final fallback: `datetime.now(UTC)`
       - Use `from __future__ import annotations`, structlog for logging
