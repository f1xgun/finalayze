<objective>
Build the bond auto-discovery pipeline: fetch all MOEX bonds from T-Invest API, apply filters (liquidity, risk, maturity), register qualifying bonds in InstrumentRegistry with FIGI mapping, fetch and cache daily bond candles, emit coupon events for upcoming ex-coupon dates, and set up coupon event infrastructure. Add ORM models for bond candle and coupon schedule caching.

Purpose: Completes the bond data pipeline by connecting T-Invest bond data to the instrument registry, event system, and candle cache. Phase 4 (BondCycleProcessor) consumes discovered bonds and cached candles for execution.
Output: BondDiscoveryService, extended TinkoffFetcher with candle fetching, CouponEvent emission, cache ORM models
</objective>

            - ru_corporate: everything else that passes filters
