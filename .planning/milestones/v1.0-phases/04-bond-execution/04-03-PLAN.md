    - Test: each fold runs BondBacktestEngine on test period only (train period used for parameter calibration context)
    - Test: aggregate walk-forward metrics combine out-of-sample results from all folds
    - Test: walk-forward results include per-fold breakdown and aggregate Sharpe, PF, max DD
  </behavior>
  <action>
1. Add `walk_forward_bond_backtest()` function to `run_bond_iteration.py`:
   - Parameters: candles_by_symbol, bond_info, coupon_schedule, strategy_fn, macro_provider, config, start, end
   - Split date range into rolling windows: 12mo train + 6mo test, rolling every 3 months (per RESEARCH recommendation)
   - This gives approximately 4-5 folds on 2022-2025 data

   - Return WalkForwardResult dataclass with per_fold and aggregate metrics

   - When enabled, call walk_forward_bond_backtest instead of single-pass engine.run()

3. Add `_run_bond_segment_walk_forward()` variant that uses the walk-forward wrapper.

4. Validate targets per user decisions:

   - Print PASS/FAIL verdict

5. Bond universe: use all OFZs from Phase 3 pipeline discovery (per user decision: "not hand-picked subset"). The script already has OFZ_PD_TICKERS and OFZ_PK_TICKERS as universe -- keep these as the default universe but note they come from the Phase 3 discovery pipeline.
