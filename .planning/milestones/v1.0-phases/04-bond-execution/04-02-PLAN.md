  <action>
1. Implement `_size_and_execute()` in `bond_cycle.py`:
   - Per user decision: iterative sizing loop (MAX_SIZING_ITERATIONS=5, SIZING_EPSILON=Decimal("0.01"))
   - Get bond info from registry, compute dirty price via bond_math.dirty_price()
   - Compute transaction_costs_per_unit from TransactionCosts config (broker commission + exchange fee per bond)
   - Call DV01BudgetStep or EqualWeightBondSizer with unit_cost=dirty_price AND transaction_costs_per_unit=costs
   - Iterative loop: compute quantity -> compute total cost (dirty_price * qty + costs * qty) -> if total > cash, reduce qty by 1 -> repeat until stable or qty=0
   - Submit order via broker_router.route("moex_bonds").submit_order()
   - Use limit orders at last price (per research recommendation) -- OrderType.ORDER_TYPE_LIMIT
   - Wait for fill: poll get_order_state every 2 seconds for up to FILL_TIMEOUT_SECONDS=120
   - On fill: update LayerLedger (add_bond_position for BUY, remove_bond_position for SELL, debit/credit cash)
   - On timeout: cancel_order, check for partial fill, keep partial if any, update ledger for partial
   - On SELL: submit sell order for full held quantity, same fill-wait logic
   - Log all order lifecycle events via structlog

2. Implement `_process_yield_stops()`:
   - Get all held symbols from ledger.bond_positions
   - If empty, return 0
   - Fetch current prices via broker_router.route("moex_bonds").get_last_prices(symbols)
   - For each position: compute current YTM via bond_math.ytm()
   - Get regime from classify_regime(macro.key_rate, macro.last_cbr_decision)
   - Call yield_stop.is_stopped_with_regime(entry_ytm_pct, current_ytm_pct, regime)
   - If stopped: submit SELL order immediately, wait for fill, update ledger
   - Return count of exits
   - Store macro reference in self._last_macro during run_cycle for access in yield stop

3. Add coupon reinvestment step to `_process_layer()`:
   - After yield stop evaluation and before strategy signal generation
   - Check for accumulated coupon cash in ledger (coupon_cash field)
   - If coupon_cash > 0, generate synthetic BUY signals weighted toward existing positions
   - Per user decision: "use accumulated coupon cash specifically to buy bonds"

4. Use `time.sleep(2)` for polling (sync context, per Pitfall 5 in RESEARCH).

5. Write tests FIRST with mocked broker, registry, and bond_math. Tests should verify the full order lifecycle including timeout and partial fill scenarios.
