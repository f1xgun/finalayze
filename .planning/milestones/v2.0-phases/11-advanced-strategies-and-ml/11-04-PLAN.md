**Step 1: Adjust MOEX minimum passing folds ratio in train_models.py**

The `evaluate_walk_forward` function in quality_gates.py accepts `min_passing_folds_ratio` parameter. With only 3 MOEX folds, a ratio of 0.60 means 2/3 folds must pass EVERY gate. This is statistically unreasonable for 3 folds (one bad fold fails everything).

In `train_walk_forward()` in train_models.py (around line 1230), find the call to `evaluate_walk_forward(all_fold_results)` and pass `min_passing_folds_ratio=0.34` for MOEX segments (1/3 folds passing is sufficient given the tiny fold count). For US segments, keep the default 0.60.

```python
# Around line 1230 in train_walk_forward():
moex_min_ratio = 0.34  # 1 of 3 folds sufficient for MOEX
min_ratio = moex_min_ratio if _is_moex_segment(segment_id) else _DEFAULT_MIN_PASSING_FOLDS_RATIO
overall_passed, gate_pass_rates = evaluate_walk_forward(all_fold_results, min_passing_folds_ratio=min_ratio)
```

Import `_DEFAULT_MIN_PASSING_FOLDS_RATIO` from quality_gates if not already imported; it is already used via the `evaluate_walk_forward` function. Actually, the default is baked into `evaluate_walk_forward`'s parameter default, so just pass the explicit value for both cases to be clear.
