<objective>
Add OFZ PK-to-PD rotation trigger to BondCycleProcessor that shifts bond layer allocations when CBR cutting cycle is detected.

Purpose: When CBR enters a cutting cycle (2+ consecutive cuts), fixed-rate bonds (PD) become more attractive than floating-rate (PK) because they lock in higher coupons before rates fall. The rotation shifts allocation from CORE (PK floaters) toward STRATEGIC (PD fixed) to capture this duration trade.

Output: apply_ofz_rotation() function integrated into BondCycleProcessor.run_cycle(), with tests covering cutting cycle detection, revert on hike, and passthrough cases.

   ```python
   def apply_ofz_rotation(
       configs: dict[PortfolioLayer, LayerConfig],
       as_of: date,
   ) -> dict[PortfolioLayer, LayerConfig]:
       """Adjust CORE/STRATEGIC allocations if CBR cutting cycle detected.

       Cutting cycle = 2+ consecutive CBR rate cuts. When active, shifts 15pp
       from CORE (PK floaters) to STRATEGIC (PD fixed) to capture duration trade.
       Reverts to original allocations if latest decision is not "cut".
       """
   ```

   Implementation:
   - Import `CBR_MEETINGS` from `finalayze.data.fetchers.cbr` (deferred import to avoid circular)
   - Filter meetings: `past = [m for m in CBR_MEETINGS if m.date <= as_of and m.decision is not None]`
   - If len(past) < 2, return configs unchanged
   - Take last 2 decisions: `last_two = [past[-1].decision, past[-2].decision]`
   - If not all `d == "cut" for d in last_two`, return configs unchanged
   - Otherwise apply rotation using `dataclasses.replace()`:
     - CORE: `replace(configs[CORE], capital_pct=configs[CORE].capital_pct - Decimal("0.15"))`
     - STRATEGIC: `replace(configs[STRATEGIC], capital_pct=configs[STRATEGIC].capital_pct + Decimal("0.15"))`
   - Return new dict with TACTICAL and SHORT unchanged

   NOTE: Use relative shift (subtract/add 0.15) not absolute values. This preserves the invariant regardless of baseline values.
