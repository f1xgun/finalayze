<objective>
Add resilience to TinkoffBroker: (1) cache last successful portfolio and return it on 70001 failure, (2) auto-reconnect gRPC channel on repeated 70001 errors.

Purpose: T-Bank API returns error 70001 intermittently, causing 62 portfolio_fetch_failed events and multi-hour blind windows during sandbox run. With cache fallback, strategy cycles continue with stale-but-usable data. With auto-reconnect, the channel recovers without waiting for manual intervention.

Output: Modified tinkoff_broker.py with portfolio cache + reconnect logic, tests proving both paths.
