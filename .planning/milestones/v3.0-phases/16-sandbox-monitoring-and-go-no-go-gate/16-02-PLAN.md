    GoNoGoReporter class:
    ```python
    class GoNoGoReporter:
        def __init__(self, thresholds: GateThresholds, market_id: str = "moex") -> None:
            self._thresholds = thresholds
            self._market_id = market_id

        async def evaluate(self, session: AsyncSession) -> GateReport:
            """On-demand evaluation reading sandbox_metrics from DB."""
            rows = await self._load_recent_metrics(session)
            sandbox_days = self._compute_sandbox_days(rows)
            now = datetime.now(UTC)

            if sandbox_days < self._thresholds.min_sandbox_days:
                return GateReport(
                    verdict=GateVerdict.DEFER,
                    criteria=[],
                    sandbox_days=sandbox_days,
                    evaluated_at=now,
                    reason=f"Insufficient data: {sandbox_days} days < {self._thresholds.min_sandbox_days} required",
                )

            criteria = [
                self._check_uptime(rows),
                self._check_fill_rate(rows),
                self._check_max_drawdown(rows),
                self._check_trade_count(rows),
                self._check_signal_frequency(rows, sandbox_days),
                self._check_critical_errors(rows),
                self._check_slippage(rows),
                self._check_signal_divergence(rows),
            ]

            critical_fails = [c for c in criteria if c.critical and not c.passed]
            non_critical_fails = [c for c in criteria if not c.critical and not c.passed]

            if critical_fails:
                verdict = GateVerdict.ABORT
                reason = f"Critical failures: {', '.join(c.name for c in critical_fails)}"
            elif non_critical_fails:
                verdict = GateVerdict.DEFER
                reason = f"Non-critical failures: {', '.join(c.name for c in non_critical_fails)}"
            else:
                verdict = GateVerdict.PROCEED
                reason = "All 8 criteria passed"

            return GateReport(verdict=verdict, criteria=criteria, sandbox_days=sandbox_days, evaluated_at=now, reason=reason)
    ```

    Private check methods:
    - `_check_uptime(rows)` -- `(max(uptime_cycles) / len(rows)) * 100` vs threshold (critical)
    - `_check_fill_rate(rows)` -- average fill_rate * 100 vs threshold (critical)
    - `_check_max_drawdown(rows)` -- `max(drawdown_pct) * 100` vs threshold (critical, inverted: actual must be < threshold)
    - `_check_trade_count(rows)` -- `sum(trade_count)` vs threshold (non-critical)
    - `_check_signal_frequency(rows, days)` -- `sum(signals_generated) / max(days, 1)` vs threshold (non-critical)
    - `_check_critical_errors(rows)` -- `sum(errors_caught) / max(len(rows), 1) * 100` vs threshold (critical)
    - `_check_slippage(rows)` -- `max(max_slippage_bps)` vs threshold (non-critical)
    - `_check_signal_divergence(rows)` -- placeholder returns CriterionResult(passed=True, actual=0.0) since no backtest comparison data available yet (documented as "engineering default" per research open question)

    `_load_recent_metrics(session)` -- query `SandboxMetricRow` WHERE market_id = self._market_id ORDER BY timestamp. Deferred import of SandboxMetricRow.

    `_compute_sandbox_days(rows)` -- count distinct dates from row timestamps.
