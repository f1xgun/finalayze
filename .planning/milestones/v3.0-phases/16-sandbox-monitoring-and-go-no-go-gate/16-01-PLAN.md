    - Import `time`, `statistics`, `collections.deque`, `structlog`
    - TYPE_CHECKING guard for `TelegramAlerter`, `AlertPriority`, `CycleMetrics`

    ```python
    class AnomalyDetector:
        _COOLDOWN_SECONDS: int = 1800  # 30 minutes
        _FILL_RATE_FLOOR: float = 0.90
        _SLIPPAGE_CEILING_BPS: float = 50.0
        _ZSCORE_THRESHOLD: float = 2.0
        _MIN_WINDOW_FOR_ZSCORE: int = 3

        def __init__(self, alerter: TelegramAlerter | None = None, window: int = 20) -> None:
            self._alerter = alerter
            self._window = window
            self._drawdown_history: deque[float] = deque(maxlen=window)
            self._last_alert: dict[str, float] = {}  # metric_name -> monotonic timestamp

        def check(self, metrics: CycleMetrics) -> list[str]:
            """Check metrics for anomalies. Returns list of triggered metric names."""
            triggered: list[str] = []
            if self._check_drawdown_zscore(metrics.drawdown_pct):
                triggered.append("drawdown")
            if self._check_fill_rate(metrics.fill_rate):
                triggered.append("fill_rate")
            if self._check_slippage(metrics.max_slippage_bps):
                triggered.append("slippage")
            return triggered
    ```

    - `_check_drawdown_zscore(self, drawdown_pct: float) -> bool` -- appends to deque, if len >= _MIN_WINDOW_FOR_ZSCORE computes mean+stdev, z-score = (drawdown_pct - mean) / stdev (guard stdev == 0), if z > _ZSCORE_THRESHOLD and cooled down -> alert, return True
    - `_check_fill_rate(self, fill_rate: float) -> bool` -- if fill_rate < _FILL_RATE_FLOOR and cooled down -> alert
    - `_check_slippage(self, max_slippage_bps: float) -> bool` -- if max_slippage_bps > _SLIPPAGE_CEILING_BPS and cooled down -> alert
    - `_is_cooled_down(self, metric: str) -> bool` -- checks `time.monotonic() - self._last_alert.get(metric, 0.0) >= _COOLDOWN_SECONDS`
    - `_fire_alert(self, metric: str, value: float, threshold: float) -> None` -- sets `_last_alert[metric] = time.monotonic()`, if alerter is not None calls `self._alerter.send_alert(text, priority=AlertPriority.CRITICAL)` with text like "Sandbox anomaly: {metric} = {value:.2f} (threshold: {threshold:.2f})"

    Write tests in `tests/unit/test_anomaly_detector.py` -- use `unittest.mock.patch("time.monotonic")` for cooldown tests. Create CycleMetrics fixtures with controlled values.
