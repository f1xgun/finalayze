<objective>
Move feature selection from per-fold execution to once-before-folds in the autoresearch pipeline, ensuring all walk-forward folds train on the identical feature set.

Purpose: Per-fold MI-based selection on ~850 samples produces noisy, inconsistent feature sets across folds. Running selection once on the full pre-test dataset eliminates fold-to-fold feature churn, improving model consistency.

Output: Modified `auto_ml_research.py` with stable feature selection + unit test proving stability.
</objective>

```python
# --- Feature selection: once before folds (FSEL-01, FSEL-02) ---
if config.feature_subset is None:
    # Aggregate all training indices across folds (exclude test to prevent look-ahead)
    all_train_indices: set[int] = set()
    for train_idx, _cal_idx, _test_idx in folds:
        all_train_indices.update(train_idx)
    sorted_train_indices = sorted(all_train_indices)

    train_df = pd.DataFrame([all_features[i] for i in sorted_train_indices])
    train_s = pd.Series([labels[i] for i in sorted_train_indices])
    selected_features = select_features_efficient(
        train_df, train_s, max_features=config.max_features,
    )
    logger.info(
        "feature_selection_stable",
        selected_count=len(selected_features),
        features=selected_features[:5],  # log first 5 to avoid noise
        experiment=config.name,
    )
    # Inject into config so _run_fold uses pre-selected features
    config = ExperimentConfig(
        name=config.name,
        description=config.description,
        strategy=config.strategy,
        feature_subset=selected_features,
        max_features=config.max_features,
        hparams=config.hparams,
    )
```

Do NOT mutate the original config object — create a new ExperimentConfig with feature_subset set. This preserves the caller's config.
