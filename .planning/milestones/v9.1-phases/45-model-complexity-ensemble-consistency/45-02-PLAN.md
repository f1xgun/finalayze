<objective>
Fix XGBoost and CatBoost class rebalancing to match LightGBM behavior: when sample_weight is provided, disable internal class weight multipliers to prevent double-rebalancing.

Purpose: XGBoost currently applies both scale_pos_weight AND sample_weight simultaneously — double-counting class imbalance. CatBoost uses auto_class_weights="Balanced" even when sample_weight is provided. LightGBM already handles this correctly (sets spw=1.0 when sample_weight present). All three must be consistent.

Output: Fixed fit() methods in xgboost_model.py and catboost_model.py, new test file proving consistency.
</objective>
