    In `_process_instrument()`, replace the sector exposure loop. Instead of using `candles[-1].close` for all
    positions, query last prices for each position symbol:
    ```python
    sector_exposure = _ZERO
    broker = self._broker_router.route(market_id)
    for pos_symbol, pos_qty in portfolio.positions.items():
        if pos_qty > _ZERO:
            # Get the last known price for this specific position
            pos_price = self._get_last_price(pos_symbol, market_id)
            sector_exposure += pos_qty * pos_price
    ```

    Add a helper `_get_last_price(self, symbol: str, market_id: str) -> Decimal` that:
    1. Tries `self._last_prices.get(symbol)` from a `_last_prices: dict[str, Decimal]` cache
    2. Falls back to fetching a single candle (or returns _ZERO if unavailable)
    Also update `_process_instrument` to cache `self._last_prices[instrument.symbol] = Decimal(str(candles[-1].close))`

    if level == self._CircuitLevel.CAUTION:
