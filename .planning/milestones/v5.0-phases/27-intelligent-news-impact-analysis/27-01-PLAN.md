    **Step 1: Create `src/finalayze/analysis/sector_ticker_mapper.py`** (per NEWS-06)

    ```python
    """Static sector-to-MOEX-ticker mapping (Layer 3).

    Maps LLM-returned sector names to concrete MOEX ticker symbols.
    No LLM needed — pure static registry.
    """
    from __future__ import annotations

    SECTOR_TICKERS: dict[str, list[str]] = {
        "oil_gas": ["ROSN", "LKOH", "TATN", "TATNP", "NVTK", "SNGS", "SNGSP"],
        "banking": ["SBER", "VTBR", "TCSG"],
        "metals_mining": ["GMKN", "NLMK", "CHMF", "MAGN", "RUAL", "ALRS", "PLZL"],
        "telecom": ["MTSS"],
        "tech": ["YDEX", "OZON", "HHRU"],
        "utilities": ["IRAO", "MSNG", "HYDR"],
        "real_estate": ["PIKK"],
        "retail": ["MGNT"],
        "transport": ["AFLT", "TRNFP"],
        "fertilizers": ["PHOR"],
        "conglomerate": ["AFKS"],
        "exchange": ["MOEX"],
        "bonds_fixed": [],   # OFZ-PD — no equity tickers
        "bonds_floating": [],  # OFZ-PK — no equity tickers
    }


    class SectorTickerMapper:
        """Maps sector names from LLM output to MOEX ticker symbols."""

        def __init__(self) -> None:
            self._all_tickers: frozenset[str] = frozenset(
                t for tickers in SECTOR_TICKERS.values() for t in tickers
            )

        def map_sectors(self, sectors: list[str]) -> list[str]:
            """Return unique tickers for given sector names. Unknown sectors are silently skipped."""
            seen: set[str] = set()
            result: list[str] = []
            for sector in sectors:
                for ticker in SECTOR_TICKERS.get(sector, []):
                    if ticker not in seen:
                        seen.add(ticker)
                        result.append(ticker)
            return result

        def all_tickers(self) -> frozenset[str]:
            return self._all_tickers
    ```

    Pydantic models for structured output:
    ```python
    class SectorImpactDetail(BaseModel):
        model_config = ConfigDict(frozen=True)
        sector: str
        direction: int   # -1 or +1
        magnitude: float  # 0.0-1.0
        reasoning: str

    class NewsImpactResult(BaseModel):
        model_config = ConfigDict(frozen=True)
        event_type: EventType
        sentiment: float       # -1.0 to +1.0
        confidence: float      # 0.0 to 1.0
        reasoning: str
        affected_sectors: list[SectorImpactDetail]
        direct_tickers: list[str]
    ```

    Class `NewsImpactAnalyzer`:
    - Constructor: `__init__(self, llm_client: LLMClient)` — stores client, loads no prompts yet (lazy)
    - Copy circuit breaker pattern from EntityExtractor: `_consecutive_failures`, `_circuit_open_until`, same threshold/reset constants
    - Lazy prompt loading: `_load_prompt(language: str) -> str` — reads from `prompts/analyze_impact_{lang}.txt`, caches in `_prompts: dict[str, str]`
    - Main method: `async analyze(self, article: NewsArticle) -> NewsImpactResult`
      - Check circuit breaker (same pattern as EntityExtractor.extract)
      - Select prompt by `article.language` ("ru" or "en", default "en")
      - Build user_prompt: `f"Title: {article.title}\n\nContent: {article.content}"`
      - Call `self._llm.complete(user_prompt, system_prompt)` — exactly ONE call (NEWS-09)
      - Parse response via `_parse_response(raw)`, reset circuit breaker on success
    - `_parse_response(self, raw: str) -> NewsImpactResult`:
      - Strip code fences using `_CODE_FENCE_RE` (copy from entity_extractor)
      - `json.loads(raw)` — on failure return `_FALLBACK_RESULT`
      - Extract `event_type` via `_PROMPT_TO_EVENT_TYPE.get(data.get("event_type", ""), EventType.OTHER)`
      - Extract `sentiment` clamped to [-1.0, 1.0], `confidence` clamped to [0.0, 1.0]
      - Extract `reasoning` as str
      - Parse `affected_sectors` list: for each entry, create `SectorImpactDetail` with direction clamped to {-1, +1} and magnitude clamped to [0.0, 1.0]
      - Parse `direct_tickers`: filter against `_VALID_TICKERS` from entity_extractor module
      - On any parse sub-error, use fallback for that field (don't fail the whole result)
    - Fallback constant: `_FALLBACK_RESULT = NewsImpactResult(event_type=EventType.OTHER, sentiment=0.0, confidence=0.0, reasoning="parse_error", affected_sectors=[], direct_tickers=[])`

    Import `_VALID_TICKERS` from `finalayze.analysis.entity_extractor` and `EventType, _PROMPT_TO_EVENT_TYPE` from `finalayze.analysis.event_classifier`. Import `_CODE_FENCE_RE` pattern — copy the regex locally rather than importing private symbol.
