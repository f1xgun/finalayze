```python
def _check_stop_losses(
    self,
    market_id: str,
    symbol: str,
    current_price: Decimal,
) -> None:
    """Check if current price has breached the stop-loss for a symbol.

    If price <= stop_loss_price, submit a SELL market order immediately.
    The entire check-sell-remove is atomic under _stop_loss_lock to prevent
    double-sell from concurrent threads (CONC-01).
    """
    with self._stop_loss_lock:
        stop_price = self._stop_loss_prices.get(symbol)
        if stop_price is None:
            return

        if current_price > stop_price:
            return

        _log.warning(
            "_check_stop_losses: stop triggered for %s @ %s (stop=%s)",
            symbol,
            current_price,
            stop_price,
        )
        broker = self._broker_router.route(market_id)
        positions = broker.get_positions()
        qty = positions.get(symbol, _ZERO)
        if qty > _ZERO:
            order = self._OrderRequest(symbol=symbol, side="SELL", quantity=qty)
            try:
                broker.submit_order(order)
            except Exception:
                _log.exception(
                    "_check_stop_losses: failed to submit stop-loss for %s", symbol
                )
                return  # Don't clear stop price -- retry next cycle
            # Update Kelly with stop-loss exit
            self._update_kelly(symbol, current_price)
        # Clear stop-loss after successful trigger (or zero position)
        self._stop_loss_prices.pop(symbol, None)
```

Key changes from current code:
1. Single `with self._stop_loss_lock:` wrapping the ENTIRE method body (was: separate lock for read, separate for clear)
2. Early return for `current_price > stop_price` inside the lock
3. On `submit_order` failure: return WITHOUT clearing the stop price (was: return after clearing nothing, but pop at end was unreachable -- now explicit)
4. `pop` at end is inside the lock (was: separate lock acquisition)

Also remove the redundant second `with self._stop_loss_lock:` block at line 1611 -- it's now inside the single lock hold.
