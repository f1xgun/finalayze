### Documented Limitations (not blockers)

1. **REST no-op gates**: `POST /experiments/{id}/apply` passes `circuit_breakers={}`, `entry_strategy_getter=lambda: {}`, `alerter=no_op`, `combiner=None` — these safety gates only activate when `PresetApplicator` is instantiated from TradingLoop context (future work)
2. **finalize_debate() not REST-accessible**: Arbiter-to-experiment escalation only via agent-orchestrator.md Python script, not REST API
3. **Multi-debate response truncation**: `POST /debates` returns only first `debate_id` when multiple debates created
