## Integration Gaps

### Bug 1: Telegram /gonogo ImportError (OPS-04)
- **File:** `src/finalayze/core/telegram_bot.py:272`
- **Issue:** `from finalayze.core.db import async_session_factory` — symbol does not exist
- **Fix:** Change to `from finalayze.core.db import get_async_session_factory` and update session acquisition
- **Impact:** `/gonogo` Telegram command always returns error. REST `/sandbox/gonogo` works fine.

### Bug 2: HealthMonitor feed freshness never updated (OPS-02)
- **File:** `src/finalayze/monitoring/health_monitor.py` — `update_feed_timestamp()` has no callers
- **Issue:** TradingLoop has no reference to HealthMonitor; `_last_feed_timestamp` stays None
- **Fix:** Wire `health_monitor.update_feed_timestamp(datetime.now(UTC))` into TradingLoop after successful data fetch, or pass HealthMonitor reference to TradingLoop
- **Impact:** `/health/production` reports feed as unhealthy; false-positive alerts after 10 min
