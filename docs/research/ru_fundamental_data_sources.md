# Источники исторической фундаменталки по РФ: что реально доступно и годится для честного бэктеста

*Памятка, RU. Без хайпа. Каждый источник оценивается честно по двум осям, которые единственно решают исход: point-in-time (есть ли реальная дата первой публикации / не подменяются ли цифры restated-значениями) и survivorship (включены ли делистнутые/ликвидированные эмитенты).*

---

## 1. Прямой ответ

Да, источники есть — и я был неправ, когда раньше подавал вывод как «исторической фундаменталки по РФ не существует». Эта стена была **про Tinkoff/T-Invest API** (он честно отдаёт только текущие значения, без истории и без даты публикации — `GetAssetFundamentals` = только «актуальные показатели»), а **не универсальный факт**. За пределами Tinkoff историческая фундаменталка по РФ существует и частично датирована: официальное раскрытие (e-disclosure.ru/Интерфакс-ЦРКИ, СКРИН, PRIME) реально несёт регуляторно-обязательную дату первого раскрытия и хранит страницы делистнутых эмитентов; ФНС ГИР БО (bo.nalog.gov.ru) даёт структурированный РСБУ почти по всем юрлицам с 2019 г.; ЦБ отдаёт формы 101/102 по банкам с 2004 г.; SmartLab (уже наш источник) несёт per-report «Дата отчёта»; открытый академический RFSD хранит РСБУ 2011–2024 с флагом неподавших. **Но** — и это следующий раздел — «данные существуют» ≠ «данные годятся для честного факторного бэктеста». Ни один *бесплатный* источник не даёт одновременно as-first-reported IFRS-консолидацию + дату публикации + делистнутых эмитентов по всему листингованному universe; а всё, что даёт настоящий point-in-time с делистнутыми (Compustat PIT, Bloomberg COFI PIT, LSEG Worldscope PIT), — институциональные western-контракты по 5 знаков в год, доступные соло-инвестору только через университетский WRDS-seat, и по РФ они заморожены на ~2021–начале-2022.

## 3. Что отличает «данные есть» от «данные годятся для бэктеста»

Исход честного кросс-секционного факторного бэктеста решают ровно **две оси**. Глубина, охват, красота API вторичны.

**Ось A — point-in-time / as-first-reported.** Фактор должен знать значение **ровно так и ровно тогда**, как его впервые увидел рынок. Источник, отдающий *текущее/пересмотренное* значение без даты первого раскрытия, — **look-ahead-ловушка, какой бы глубокой ни была история**: (1) исправленная отчётность замещает исходную → «знаешь» цифру, которой на дату сделки ещё не было; (2) без даты публикации нельзя честно лагировать признак. T-Invest — учебниковый пример: всегда отдаёт «сейчас», физически не может сказать *когда* цифра стала известна. То же с ISSUESIZE (текущий снимок → historical market_cap искажён любым buyback/SPO/split).
- Ось A **держат**: официальное раскрытие (e-disclosure/СКРИН/PRIME) и цены MOEX ISS.
- **Частично**: SmartLab (реальная «Дата отчёта», но значения restated), ЦБ-формы, RFSD (год подачи).
- **Не держат**: ГИР БО (`unknown`), СПАРК/Контур, Tinkoff, Investing.com.

**Ось B — survivorship.** Фактор на universe, из которого лузеры выпали by construction, **систематически завышает премию**. Худший нарушитель назван честно: **ГИР БО с 2020 исключает финальные отчёты ликвидированных** — дефолтёр пропадает вместе с терминальным годом. SmartLab и ритейл survivor-biased. Ось B **держат**: официальное раскрытие, MOEX ISS (`is_traded=0`), RFSD, western PIT-вендоры.

**Вывод раздела:** «данные есть» (ГИР БО, огромный РСБУ-охват) ≠ «данные с доверенным историческим as-of и делистнутыми». Второе дают только агентства раскрытия (после тяжёлого извлечения чисел из вложений), RFSD (с оговорками), или институциональные western-вендоры.

## 4. Реалистичный путь (ранжировано по трейд-оффу)

**(i) Официальная point-in-time спина — e-disclosure/Интерфакс + ГИР БО как cross-check.** Единственная *бесплатная* конфигурация, держащая **обе** оси. Ось A: реальная дата первого раскрытия. Ось B: делистнутые сохранены.
- Честность: высшая из бесплатных. Усилие: **тяжёлое** (числа в PDF/XLS/XML → нужен format-varying экстрактор; universe делистнутых собирать по ~5 агентствам). Стоимость: free = только scraping (ToS/rate-limit риск). Оговорка: пост-2022 юр. редакции пробивают дыры в свежей крупнокэп-фундаменталке.

**(ii) Расширить наш SmartLab + ISS backfill (уже построен).** `scripts/backfill_fundamentals.py` (survivor-list `BLUE_CHIPS:89`; +75d/+120d disclosure-lag as_of), `smartlab_fundamentals.py` (стампит `FundamentalSnapshot.as_of` по «Дата отчёта», runtime robots.txt-проверка), `moex_iss.py` (дивиденды по `registryclosedate`, reconstruct_market_cap). Задокументировано в `docs/research/moex_historical_fundamentals_spike.md`.
- Честность: средняя. Обходит грубейшую fiscal-quarter-end ловушку (реальная дата раскрытия), но **три** дефекта: значения restated (не as-first-reported); живые таблицы ~5 кв/~5 лет; **нет делистнутых** (survivor-biased, ручной `BLUE_CHIPS`). Усилие: низкое-среднее (уже есть). Стоимость: free. Годно для disclosure-lag среза на голубых фишках; **не** для restatement-clean survivorship-aware глубокой панели.

**(iii) Платный point-in-time вендор.** Настоящий as-first-reported + делистнутые — только Compustat PIT / Bloomberg COFI PIT / LSEG Worldscope PIT.
- Честность: высшая. Стоимость/доступ: 5 знаков/год enterprise; соло — только университетский WRDS-seat. **Санкционный блокер:** пост-2022 РФ-фундаментал заморожен ~2021/начало-2022 — источник-side дыра, вендор не закроет. Чистое окно — грубо **pre-2022**.

*(Отдельно, самый честный бесплатный не-институциональный вариант: **RFSD** — CC BY 4.0 Parquet, хранит ликвидированные, флагует непод., не переписывает restated. Но РСБУ-unconsolidated ≠ IFRS-консолидация, которую рынок оценивает у холдингов; entity-indexed → INN→тикер самому; пост-2022 разрежён. Годен как прозрачная спина, cross-check против IFRS ~50 ликвидных имён.)*

## 5. Честный вывод

**Да, честный фундаментальный факторный бэктест по РФ ДОСТИЖИМ — но с материальным объёмом работы и с двумя остаточными оговорками, которые нельзя устранить, только объявить.**

Достижимо: look-ahead-free **цены + членство в индексе** из MOEX ISS (уже в проде) + **датированная point-in-time спина** из официального раскрытия (реальные даты + делистнутые) + (при наличии инженерного времени на экстрактор из вложений) срез, честно проходящий обе оси **для pre-2022 окна**.

Два дефекта **структурны, не устранимы усилием**:
1. **РСБУ-vs-IFRS.** Всё бесплатное построчное (ГИР БО, RFSD, ЦБ-формы) — **РСБУ unconsolidated**, экономически иное, чем IFRS-консолидация, по которой рынок оценивает листингованные холдинги. Честная IFRS-консолидация с датой первой публикации — только у western PIT-вендоров (заморожены по РФ) или запертой во вложениях e-disclosure (тяжёлый экстрактор).
2. **Разрыв 2022.** Источник-side blackout (юр. право эмитентов скрывать + пауза/редакция ЦБ + уход western-вендоров), не артефакт вендора. Любой фактор в 2022+ смещён на *ровно тех* крупных/санкционных именах, что фактор-модели важны.

Поэтому бэктест look-ahead-safe только при: (a) консервативном лаге фундаментала к дедлайну подачи (уже делаем +75d/+120d), (b) явном принятии РСБУ-vs-IFRS mismatch либо плате за IFRS-PIT, (c) спец-обработке разрыва 2022 как отдельного режима, (d) явной пометке, что месячные as-of винтажи и security-level делистнутый universe вне институциональных paywall-вендоров недоступны.

**Привязка к депозит-якорю.** Даже в лучшем достижимом варианте это pre-2022 окно, РСБУ-приближение, тонкая крупнокэп-панель с ручным survivor-листом. Такой фактор — **гипотеза edge, не подтверждённый edge**; его honest-bar — обогнать **депозит под 16–21%**, не индекс. Рациональный порядок: депозит остаётся якорем аллокации, фундаментальный фактор строится как **измеряемый, честно-оговорённый эксперимент** поверх пассивного equity-рукава — «measure, don't assert». Достижимо — да. Достаточно, чтобы сместить капитал с депозита на фактор-сигнал — **пока нет**, и данные-side этого честно не позволяют утверждать.

## 6. Разведка RFSD — проверено на реальных данных (2026-07-07)

Скачал партицию `year=2021` (единый parquet, 559 МБ, 3 411 371 фирм-строк, 2 326 377 с `filed=1`), прочитал схему через range-запросы, посчитал локально, файл удалён.

**Подтверждено (годится):**
- Датасет реальный, рецензируемый (Nature Scientific Data `s41597-025-05150-1`), бесплатный, HF `irlspbru/RFSD` + Zenodo, Apache Parquet с годовой партицией, 2011–2024, ~6.6 ГБ суммарно (~559 МБ/год), можно тянуть один год/колонки.
- Схема: **213 колонок**. Ключи `inn`, `ogrn`, `okved`, `okved_section`, `region`, `region_taxcode`, `filed`. **Имени фирмы НЕТ** → нужен кроссволк тикер→ИНН.
- Метрики: выручка `line_2110`, **готовая валовая прибыль `line_2100`**, активы `line_1600` (внеоборотные `line_1100`), ЧП `line_2400`. → **GP/A = `line_2100`/`line_1600` считается напрямую** (сильнейший quality-фактор).
- **Мега-капы присутствуют с реальными standalone-РСБУ** (по верным ИНН, 2021, ₽ тыс.): GAZP (7736050003) выручка 6.39 трлн, GP/A 0.179, ЧП 2.68 трлн; LKOH (7708004767) 2.39 трлн, GP/A 0.402; TATN (1644003838) 1.07 трлн, GP/A 0.275; NVTK (6316031581) 0.73 трлн, GP/A 0.216; MTSS (7740000076) 0.37 трлн, GP/A 0.204.

**Два подвоха, продемонстрированы на данных (не теория):**
1. **Банков нет.** SBER (ИНН 7707083893) **отсутствует** в RFSD — банки сдают отчётность по форме ЦБ, а не по РСБУ-форме ФНС (ГИР БО), которую собирает RFSD. VTB/TCS так же → весь финсектор дыра, нужен отдельный источник (формы ЦБ 101/102).
2. **Холдинг-пустышка реальна.** ПАО «Магнит» (2309085638) показывает выручку **712 млн ₽** (GP/A 0.003) — пустой холдинг; операционка в АО «Тандер» под другим ИНН. Для холдингов ИНН листингованной бумаги ведёт в пустышку → маппить на операционную «дочку». Это РСБУ-unconsolidated-оговорка вживую.

**Прочее:**
- **Лицензия — расхождение:** HF-карточка декларирует **CC BY 4.0**; страница arXiv показывала иконку CC BY-**NC-SA** 4.0. Для личного исследования безразлично (NC не блокирует, SA — только при редистрибуции), но перед любым коммерческим/публичным использованием подтвердить по Zenodo-записи.
- Кроссволк тикер→ИНН строить из **авторитетного** источника (при разведке 5 из 12 ИНН оказались неверными/с гэпами — часть реальные дыры типа банков, часть мои ошибки). Разовая задача ~50–100 строк.
- HF **анонимно троттлит** (429) тяжёлые range-запросы → для работы качать по-годовые файлы разово и считать локально; HF_TOKEN не ставим (подписочный принцип).

**Итог разведки:** RFSD годен как бесплатная survivorship-aware РСБУ-спина; сильнейший фактор (profitability/GP-A) считается чисто на верифицированных нефинансовых мега-капах уже сегодня. Честный pre-2022 profitability-эксперимент **достижим** при: (a) исключении/отдельной обработке банков, (b) маппинге холдингов на операционные «дочки», (c) явных оговорках РСБУ-приближение/годовые/pre-2022/тонкая-панель, (d) мере против депозита, не индекса.

## 7. Кроссволк + покрытие IMOEX — проверено на RFSD 2019/2020/2021 (2026-07-07)

Резолвнул 42 эмитента IMOEX (тикер→ИНН, холдинги→операционные дочки, все confidence=high с источниками), провалидировал каждый ИНН против RFSD за **три года**. Артефакт: **`docs/research/moex_fundamental_crosswalk.csv`** (маршрутизация источников + rfsd_usable + REGN банков). Банковский путь ЦБ: формы 101/102, ticker→REGN (SBER 1481, VTBR 1000, BSPB 436, CBOM 1978, SVCB 963, T/ТБанк 2673, DOMRF 2312), ROA/ROE = ЧП(форма102 симв.01000−03000)/активы(форма101 ITGAP); MOEX+RENI как НФО в формы ЦБ 101/102 НЕ сдают.

**КРИТИЧЕСКОЕ покрытие (системно, не случай одного года):**
- **RFSD-usable (GP/A считается), ~18 нефин. имён:** GAZP, LKOH, TATN, NVTK, MTSS, AFLT, MSNG, UGLD, PHOR + холдинг-дочки X5→Агроторг (GP/A 0.87–1.04), YDEX, VKCO, LENT, MDMG, HEAD, CNRU, RAGR; частично OZON/POSI.
- **RFSD NULL во ВСЕХ трёх годах → нужен issuer IFRS:** **весь сектор металлов и добычи** — GMKN, PLZL, CHMF, NLMK, MAGN, ALRS, RUAL — **плюс ROSN, SNGS, RTKM, IRAO, FLOT, ENPG, AFKS**. Причина: крупнейшие налогоплательщики сдают РСБУ через межрегиональные инспекции ФНС и **не попадают в открытый ГИР БО**, на котором построен RFSD.
- **Банки (ЦБ, ROA/ROE не GP/A):** SBER, VTBR, T, SVCB, CBOM, BSPB, DOMRF (~24% веса индекса).
- **По весу** RFSD покрывает ~55–60% IMOEX (потому что два крупнейших, LKOH 15.6% + GAZP 9.2%, внутри), **но по числу имён для КРОСС-СЕКЦИОННОГО фактора** это ~18 нефин. бумаг с **дырой во всём металло-горном секторе** — тонкое, секторно-перекошенное сечение (нефтегаз + потреб/техи, без металлургии).

**Что это значит для profitability-бэктеста:** честный GP/A-фактор из RFSD строится на ~18 нефинансовых именах pre-2022, системно без металлургии; банки идут отдельным ROA/ROE-рукавом через ЦБ; металлурги/Роснефть/Сургут требуют отдельного IFRS-сорсинга (e-disclosure/IR). Полная панель ⇒ либо принять секторный перекос RFSD-рукава, либо доклеить IFRS для ~14 NULL-имён (тяжелее). Валидация поймала бы молчаливое выпадение половины индекса до бэктеста.

## 8. Закрытие металло-дыры через SmartLab-IFRS — и итоговый потолок данных (2026-07-07)

Проверил наш существующий `smartlab_fundamentals.py` (умеет `/f/y/MSFO/` и `/f/q/MSFO/`, робот-гейт, стамп «Дата отчёта»). Страница MSFO отдаёт **полную IFRS-consolidated батарею** (64 `@field`): `revenue`, `cost_of_production` (→ валовая), `operating_income`, `ebitda`, `net_income`, `assets`, `net_assets`(капитал), `net_debt`, готовые `ev_ebitda/p_e/p_s/p_bv/roe/roa`, `date`(дата раскрытия).

**Металло-дыра ЗАКРЫВАЕТСЯ — на реальных числах (IFRS, FY2021):** GMKN выручка 1317 млрд / cost 427.6 / активы 1741 → **GP/A 0.51**; CHMF 0.74; NLMK 0.63; ROSN (выручка 8761 млрд) 0.13. Всё с реальными датами раскрытия (10.02.2022 и т.д.). Это правильная база (IFRS-консолидация = что оценивает рынок и на чём считается Novy-Marx GP/A) → можно взять SmartLab-IFRS **единым источником для всех нефин. имён**, RFSD оставить кросс-чеком.

**НО — решающее ограничение глубины:** и годовая, и квартальная страница SmartLab отдают только **~5–6 последних периодов** (GMKN квартально ~6 кв.; годовая FY2021–2025). Глубокой истории на скрейп-виде НЕТ.

**Итоговый потолок данных (проверено на реальных данных, не теория):**

| Источник | Глубина | Полнота вселенной | База | Чистое pre-2022 |
|---|---|---|---|---|
| **RFSD** | 2011–2021 (глубоко) | ~18 нефин., **без металлургии/банков** | РСБУ-standalone | да |
| **SmartLab IFRS** | ~5–6 периодов (2021–2025) | **вся вселенная вкл. металлургов** | IFRS-consolidated (верно) | нет (пост-2022 режим) |
| **ЦБ формы 101/102** | 2004→ (глубоко, банки) | только банки | РСБУ-регуляторные | да (кроме дыры 2022→сер.2023) |
| institutional PIT (Compustat/Bloomberg/LSEG) | глубоко+полно | всё | IFRS as-first-reported | **заморожено по РФ ~2021** |

**Ни один бесплатный источник не даёт одновременно ГЛУБИНУ + ПОЛНОТУ + ЕДИНУЮ БАЗУ + чистое pre-2022.** Глубокий survivorship-aware (RFSD) без металлургии/банков и в РСБУ; полный правильно-базовый (SmartLab IFRS) мелкий и пост-2022. Значит любой честный фактор-тест выйдет либо **тонким** (RFSD: 18 имён без металлов) либо **коротким** (SmartLab: ~5 сечений в диком 2022-режиме) — **статистически неубедительным по построению**. Кредибельный глубокий+полный+PIT-фактор по РФ живёт только за институциональным paywall, замороженным санкциями с ~2021. Это тот же потолок, к которому проект приходит по всем полосам: сигнал данными не достаётся — **депозитный якорь держится**.
